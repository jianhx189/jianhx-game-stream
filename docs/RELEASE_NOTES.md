# MiniStream 2.3.4

- 「我的设备」使用统一的添加入口和设备菜单，提供连接、修改名称、检测连通性和移除。邀请导入后会保存各台设备的连接配置，切换前显示当前设备名称并请求确认。
- 被控端首页「你要如何连接」集中处理局域网与 FRP 邀请、主机状态及已连接设备。「串流质量」包含媒体会话和连接指标。「服务与诊断」集中处理本机自检、后台服务、端口与日志。
- 新版邀请可包含一次性配对授权。被控端控制台在托盘运行时，主控端导入后自动执行 Moonlight 与 Sunshine 配对。授权有效期为 10 分钟，旧邀请或不可用授权仍可使用 PIN。
- 连通性检测启动空闲被控端的 Desktop 或桌面应用，预热约 2 秒并采样 12 秒。报告记录实际视频帧率、媒体 RTT、丢帧、解码与音频提交。音视频样本齐全时按 100 分制给出本次配置的远程游戏评分。
- 主控端用当前运行程序的版本检查正式更新，可忽略指定版本。

评分权重为帧率 35、网络丢帧 30、媒体 RTT 20、音频提交率 15。检测使用当前串流设置，结果随路线、主机负载与桌面内容变化。
