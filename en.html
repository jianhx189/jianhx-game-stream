Native applications. Actual connection information.

The controller provides device cards, pairing, a wizard and an in-session menu. The host console shows authenticated sessions, transport, tunnel RTT and jitter, throughput, services, settings and diagnostics. Media statistics come from the controller while streaming; missing or stale samples are shown as a dash.

This is a real application window from the 2.1 series, captured without an active session. It is not a performance benchmark.

A verified UDP reply fix

2.1.2 fixes a reproduced multi-interface Windows issue: incoming probes reached one local address, but replies left another. The host now preserves the incoming destination address and interface for both probe and media replies. The affected forwarded connection recovered from TCP fallback to UDP.

UDP fallback remains available when necessary. Port multiplexing does not recompress video or guarantee lower latency. Tunnel RTT is not end-to-end input delay, and media frame loss is not IP packet loss.

Three steps to your own computer

Install Host on the gaming PC, prepare a reachable LAN or your own TCP/UDP forwarding, and install Client on the PC you operate. Enter your actual public ports and private tunnel credentials, complete pairing, then launch a desktop or game.

No MiniStream cloud account or public relay is provided. The current tunnel supports one authenticated controller at a time. End active sessions and preserve configuration before upgrading both ends.

Transparent scope and open source

This regular release includes verified builds, protocol tests, burst/replay checks and the reproduced forwarding fix. Comprehensive clean Windows 10/11 installation, all driver combinations and long WAN gaming sessions remain ongoing work. Actual experience depends on your hardware and network.

The custom authentication and key exchange are not security-audited and must not be treated as a complete encrypted VPN. Use a trusted protected network path and keep credentials and Sunshine management access private.
