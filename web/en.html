BEFORE YOU CONNECT

Understand the limits
before you connect.

Do two ports guarantee cross-network access?+

No. Port mappings, firewall rules, credentials and bidirectional UDP still need to be correct. Test the LAN first; a local listener alone does not prove public reachability.

Are RTT, frame loss and game latency the same?+

No. Tunnel RTT is not end-to-end input delay, and network frame loss is not IP packet loss. Use events from both ends together with decode and queue timings.

What changed after the 2.1.3 regressions?+

Version 2.1.4 fixed first-save failure and sockets left by failed startup; 2.2 carries those fixes forward. End streaming, preserve configuration and upgrade both ends together.

Is local password protection end-to-end encryption?+

No. DPAPI and file ACLs only reduce local file exposure. The same Windows user can decrypt the values, and plaintext remains in memory. Use a trusted protected network path for public deployment.

Do the screenshots show measured gaming performance?+

No. They show actual new-version applications offline or under test to demonstrate the interface and information structure.
